# 后端开发工程师 JD 关键词库

## 核心技术栈

Java、Spring Boot、Spring Cloud、MyBatis、MySQL、Redis、Kafka、RabbitMQ、Nginx、Docker、Kubernetes、Linux、Git

## 常见要求关键词

- 微服务、分布式、高并发、高可用、负载均衡
- RESTful API、RPC、gRPC、Dubbo
- 数据库优化、索引、SQL 调优、分库分表
- 缓存、消息队列、异步处理
- CI/CD、自动化部署、DevOps
- 单元测试、JUnit、Mockito、测试覆盖率

## 项目经验加分项

- 参与过完整项目周期（需求→设计→开发→测试→上线）
- 有性能优化经验（QPS 提升响应时间降低）
- 有分布式系统实践（微服务拆分、服务治理）
- 有开源贡献或技术博客
- 参与过 ACM/算法竞赛

## 常见面试考点

- JVM 原理、垃圾回收机制
- 并发编程（线程池、锁、CAS）
- MySQL 索引原理、事务隔离级别
- Redis 数据结构、持久化、缓存策略
- 分布式锁、分布式事务
- 设计模式（单例、工厂、策略、观察者）
