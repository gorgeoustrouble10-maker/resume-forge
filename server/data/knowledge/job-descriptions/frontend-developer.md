# 前端开发工程师 JD 关键词库

## 核心技术栈

JavaScript、TypeScript、React、Vue、Next.js、HTML5、CSS3、Webpack、Vite、Node.js、Git

- 组件化、模块化、单页应用、SPA、SSR
- 状态管理、Redux、Zustand、Pinia、Context
- 响应式设计、移动端适配、跨端
- HTTP、HTTPS、WebSocket、Fetch、Axios
- 性能优化、懒加载、虚拟列表、首屏加载
- 测试、Jest、Vitest、Cypress、测试覆盖率
- 工程化、CI/CD、ESLint、Prettier、Husky

## 项目经验加分项

- 参与过完整前端项目（设计→开发→部署）
- 有性能优化经验（Lighthouse、首屏、包体积）
- 有跨端经验（小程序、Electron、React Native）
- 有组件库或工具开发经验
- 有开源贡献或技术博客
- 参与过前端架构设计
